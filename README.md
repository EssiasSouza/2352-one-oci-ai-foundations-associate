# 2352 - ONE - OCI AI Foundations Associate

Bienvenido al repositorio oficial de apoyo del curso **2352 - ONE - OCI AI Foundations Associate**, disponible en **Alura**.

Este repositorio reúne los scripts utilizados durante las demostraciones prácticas del curso para facilitar el seguimiento de las clases. Puedes utilizarlos para copiar y pegar el código durante las demostraciones, evitando tener que escribirlo manualmente mientras acompañas el contenido.

## Contenido del repositorio

Los siguientes archivos corresponden a las demostraciones realizadas en las clases:

| Clase | Archivo |
|--------|---------|
| 2.4 - Demostración: Introducción al Jupyter Notebooks | `demo_intro_al_jupyter_notebooks.py` |
| 2.5 - Demostración básica de ML (Parte 1) | `demo_basica_de_ml_parte_1.py` |
| 2.6 - Demostración básica de ML (Parte 2) | `demo_basica_de_ml_parte_2.py` |
| 3.4 - Demo: Clasificación con Perceptrón multicapa | `demo_clasificacion_con_perceptron_multicapa.py` |

## Objetivo

El propósito de este repositorio es servir como material de apoyo para los estudiantes del curso.

Los scripts fueron preparados para ser utilizados durante las clases y pueden copiarse y pegarse directamente en los entornos de demostración, como **Jupyter Notebooks**, permitiendo que el estudiante se concentre en comprender los conceptos presentados en lugar de escribir el código desde cero.

## Requisitos

Para ejecutar los ejemplos, se recomienda contar con:

- Python 3.10 o superior
- Jupyter Notebook o JupyterLab (cuando corresponda)
- Las bibliotecas indicadas durante el curso
- Un entorno configurado según las instrucciones de las clases

## Importante

Estos scripts tienen un propósito exclusivamente educativo.

En algunos casos, el código ha sido simplificado para facilitar la comprensión de los conceptos de **AI** y **ML**. Por esta razón, no representan necesariamente las mejores prácticas para entornos de producción.
